Three claims, each with proof attached

Everything here is one click from the code that produced it.

01Runs by itself

I ship things that run unattended.

I built a model that predicts how the Premier League season will finish. It updates itself every week, then marks its own past predictions to show whether it was right. I don't touch it.

PL Supercomputer 02What didn't work

I publish what didn't work.

Four ideas I tried didn't make the model any better. So I switched them off and wrote down the numbers that proved it. The code for the failed versions is still public.

What I got wrong 03Limited downside

I make being wrong cheap.

My fantasy football bot uses AI to read team news, but it's only allowed to mark a player down, never up. If the AI is wrong, it costs me one player instead of my whole team.
